REAPER C++ Console

This is an image-based walkthrough of the verified Week 2 console run. Week 3 additionally includes task summary counts, priority sorting, CPU/memory snapshots, and CTest regression coverage.

How the console works

1. Create a task and choose a priority. 2. View tasks by status. 3. Complete a task by ID. 4. Review the updated status and exit. The console validates numeric input and explains invalid choices instead of unexpectedly ending a session.
